# More Than a Prompt — Book material

Companion repository for **"Más que un prompt"** (Henry Ramírez Reyes, Studio35).

The book teaches the terminal, Git and the AI working cycle: cloning this repository is real practice from chapter 7. Long fragments live under `capitulos/`; the three book projects under `proyectos/`.

## One repository, three editions

This repository is shared by the Spanish, English and French editions of the book. The code is single-source (English identifiers); each edition prints the fragments with comments in its own language.
